# Figure-label snapshot before B5

These three files are the former SI Fig. 4 exports and writing copy, preserved
at their original relative paths. The right-hand panels misleadingly labelled
the combined severe-category output as P4 while showing an empty P5 column.
The current figure displays combined predicted P4/5 in one column and retains
all five actual classes. This is a display-only revision: source predictions,
confusion-count CSVs and numerical model results were not changed.

To restore a former figure, copy the required file back to its package-relative
path only after checking that no newer output will be overwritten. These are
historical presentation artifacts, not the current manuscript figures.
